
# Vaibhav-Portfolio

A personal portfolio website built with React.js, showcasing my projects, skills, resume, and GitHub activity.

## Tech Stack

- React.js (Create React App)
- React Router
- React Bootstrap
- react-tsparticles, react-parallax-tilt, typewriter-effect for UI effects
- react-github-calendar for GitHub contribution stats

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm start
```

The app will be available at `http://localhost:3000`.

To create a production build:

```bash
npm run build
```
